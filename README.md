# algorithm

C++로 푼 알고리즘 문제와 학습 기록을 모으는 저장소입니다.

| 주제 | 파일 |
| --- | --- |
| DFS | `dfs-*.cpp` |
| BFS | `bfs-*.cpp` |
| 최단 경로 | `shortest_path-*.cpp` |
| 동적 계획법 | `dp1-*.cpp` |
| 백트래킹 | `backtracking-*.cpp` |
| 이진 탐색 | `parmetric_search-*.cpp` |
| 누적 합과 시간 복잡도 개선 | `shorten_time-*.cpp` |

각 소스 파일은 독립적으로 실행하는 문제 풀이입니다.

## 학습 기록 올리기

파일을 저장한 뒤 이 폴더의 터미널에서 실행합니다.

```bash
git add .
git commit -m "study: 풀이한 문제와 학습 내용"
git push
```

VS Code의 소스 제어에서도 변경 파일을 스테이징하고, 커밋 메시지를 입력한 다음 Push할 수 있습니다.

실행 파일, 로컬 설정, 실습일지 문서는 `.gitignore`로 제외합니다.
